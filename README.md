# Botix: demostración

Web pública de [Botix](https://diegom1313.github.io/botix-demo/), con todo lo que vende Botix y **Bix**, un asistente que lo explica a fondo.

## Qué hay

- `index.html`, `estilos.css`, `web.js`: la web (servicios, sectores, precios, preguntas).
- `bix.js`: Bix, el asistente. Responde sobre el asistente de citas, los canales, las webs, la auditoría SEO, los cobros, los precios, la privacidad y la baja, y puede simular cómo reserva una cita el asistente de una barbería ficticia.
- `og.png`: la imagen que sale al compartir el enlace.

Bix funciona solo en el navegador: no guarda ni envía lo que se escribe. Para que enlace al alta o dé un contacto real, rellena `CONFIG` al principio de `bix.js`.

No usa vídeos ni imágenes de terceros: la esfera de luz del héroe se dibuja en el navegador y la puerta de luz del final es CSS.

El código del producto no está aquí: es privado.
